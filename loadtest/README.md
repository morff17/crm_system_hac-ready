# Нагрузочный тест

Установить `locust` и запустить:

```bash
CRM_USER=user CRM_PASSWORD=user123 locust -f loadtest/locustfile.py --host http://SERVER
```

В Web UI Locust выставить 50 пользователей. Для проверки отчётов отдельно можно запустить 10 пользователей с task `report`.
Целевой критерий ТЗ: 50 параллельных пользователей и не менее 10 параллельных отчётов. Фактические показатели зависят от CPU/RAM/IO сервера и должны фиксироваться на целевом стенде.
